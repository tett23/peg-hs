usage: peg-hs fmt [options] [FILE|DIR...]

Format grammars in place, in the one style of peg-hs. Comments are kept.
A directory stands for the .hpeg files under it. Without arguments, format every .hpeg
file under the current directory. Directories whose name starts with . and
dist-newstyle are skipped. Files are read and written as UTF-8.

options:
  --check                   write nothing; list the files that are not formatted and fail if any
  -h, --help                show this help

examples:
  peg-hs fmt
      format every grammar under the current directory
  peg-hs fmt --check grammar
      list the grammars under grammar that are not formatted, and fail if any
