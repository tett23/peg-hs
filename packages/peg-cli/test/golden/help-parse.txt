usage: peg-hs parse [options] GRAMMAR.hpeg INPUT

Parse INPUT with the grammar and show the value of the start rule (the AST)
or the lossless syntax tree (the CST). The parser is compiled with the ghc on PATH
(GHC 9.10, 9.12 or 9.14), and cached under $XDG_CACHE_HOME/peg-hs/parse. The AST needs
a Show instance of the type of the start rule. Run through cabal exec to use the
packages of a project. Grammars with %env are not supported. Files are read as UTF-8.

options:
  --format ast|cst|all      what to show (default: ast)
  --entry RULE              parse with a rule of %entry instead of the start rule
  --ghc-arg ARG             pass ARG to ghc, such as -isrc (repeatable)
  -h, --help                show this help

examples:
  peg-hs parse Expr.hpeg input.txt
      show the value of the start rule for input.txt
  peg-hs parse --format cst Expr.hpeg input.txt
      show the lossless syntax tree
  cabal exec -- peg-hs parse --ghc-arg -isrc G.hpeg in.txt
      compile with the packages of the project and the modules under src
