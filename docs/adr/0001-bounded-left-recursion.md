# ADR 0001: 左再帰の意味論として bounded left recursion を採用する

ステータス: 採択

## 文脈

素朴な PEG 実装では、左再帰の規則（`E <- E '+' n / n`）は入力を消費しないまま自分自身を呼び、無限再帰に陥る。
左再帰を扱う既知のアプローチは三つある。

1. **Warth et al. 2008（seed-growing）**：メモ表に失敗を種として置き、成長が止まるまで再評価する。実装例は多いが、間接左再帰で結合性が壊れる反例が知られており（Tratt 2010）、正当性の形式的な根拠を欠く。
2. **Medeiros et al. 2014（bounded left recursion）**：左再帰の展開回数に上限 n を与えた意味論 A^n を定義し、n を増やして到達可能な最長の一致を規則の結果とする。形式意味論が論文で定義されており、直接・間接の左再帰の両方を扱える。
3. **静的左再帰除去**：生成時に文法を書き換えて左再帰を消す。ランタイムは単純になるが、構文木の形が変わるため再結合アクションの合成が必要になる。型付きアクション（[ADR 0003](0003-typed-semantic-actions.md)）の下では中間型の発明が必要になり、複雑さが逆転する。間接・隠れ左再帰の検出と変換も自前で持つことになる。

## 実装すること

- Medeiros らの bounded left recursion を peg-runtime の意味論として採用する
- 左再帰に関与する規則の呼び出しは、メモ表に失敗を初期値として置き、規則本体の評価と結果のメモ表への書き戻しを、一致長が伸びなくなるまで反復する。一致長が縮んだ時点で直前の結果を確定する
- 左再帰に関与する規則の判定は peg-grammar の静的検査（規則参照グラフ上の解析）で行い、生成コードは該当規則にのみ成長ループを配線する
- 左再帰に関与しない規則は通常のパックラット評価とし、成長ループのコストを負わせない

## 実装しないこと

- Warth 方式の involved-rule set / head の管理は実装しない
- 静的左再帰除去は実装しない
- 展開上限のユーザー指定は設けない。上限は意味論上の道具であり、実装は一致長の単調性による停止判定で置き換える

## テスト設計

- **直接左再帰**：`E <- E '+' n / n` が `n+n+n` を左結合の木 `((n+n)+n)` にすること
- **間接左再帰**：Medeiros 論文の例（`L <- P '.x' / 'x'` と `P <- P '(n)' / L`）が論文の与える結果と一致すること
- **隠れ左再帰**：nullable な式を前置した左再帰（`E <- A? E '+' n / n` の形）の挙動を意味論と突き合わせて確認する。意味論の枠外であることが判明した場合は静的検査で拒否し、その決定を新たな ADR に記録する
- **右再帰との共存**：右再帰で書いた規則が右結合の木を生じ、左再帰規則と同一文法内で共存できること
- **非左再帰文法の回帰**：左再帰機構の追加が、左再帰を含まない文法の結果を一切変えないこと（成長ループ導入前後で結果を比較するプロパティテスト）

## トレードオフ

- 左再帰に関与する規則はメモ化が必須になり、規則単位の no-memo 指定（未決事項）の対象外になる
- 成長ループの反復により、左再帰規則の評価は非左再帰規則より定数倍遅い。最悪計算量の保証は未決事項として残す
- セマンティックアクションは成長の各反復で再実行されるため、純粋性の要求（仕様書「意図的に採用しなかったもの」）がこの決定の前提になる
