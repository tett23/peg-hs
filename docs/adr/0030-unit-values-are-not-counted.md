# ADR 0030: `()` の値を、グループとアクションの省略で数えない

ステータス: 採択

## 文脈

ADR 0004 は、括弧のグループの値を「内側の逐次が値をちょうど一つ持つときその値」とし、アクションを省略した選択肢も、値を持つ要素がちょうど一つのときだけ認めた。
値を持つ要素には、型が `()` の規則の呼び出しも含まれる。

空白やコメントを読む規則は、ほとんどの文法で型が `()` である。
そのため、空白を挟むだけで値の数が増え、グループに値がなくなる。

```
ExpList <- e:Exp es:(',' Sp Exp)* { e : es }   # Sp :: () も値に数えられ、グループは値を持たない
```

Lua の文法（ADR 0022）では、これを避けるために `MoreExp`、`MoreName`、`MoreVar`、`DotName`、`ColonName`、`Init`、`CommaVarArg` などの補助の規則を立てた。
TOML の文法（ADR 0023）でも、`MoreElement`、`MoreInlineKeyVal` を立てた。
補助の規則は、文法の見通しを悪くし、規則ごとに型注釈とアクションを書かせる。
Golem の文法も空白を規則で読むので、同じことが起きる。

`()` の値は情報を持たない。
束縛しない `()` の値を数えから外しても、利用者が失う値はない。

## 実装すること

### 単位の値

次の式を、値が単位（`()` だけからなる値）の式と呼ぶ。

- 型注釈が `()` の規則の呼び出し。型注釈の判定は、空白を除いた文字列が `()` であることで行う
- 値が単位の式に `*`、`+`、`?` を付けたもの（値は `[()]` や `Maybe ()` になる）
- 値が単位の式に失敗ラベルを付けたもの
- 値を持つ選択肢のすべてで、値が単位の要素だけが値を持つグループ

### 数え方

- 括弧のグループの選択肢と、アクションを省略した選択肢では、値を持つ要素を数えるとき、束縛しない単位の要素を数えない
- ただし、単位でない値を持つ要素が一つもない場合は、これまでどおり単位の要素も数える。`Spaces <- Ws` のように、`()` の規則をそのまま渡す選択肢は、これまでどおり書ける
- 束縛した要素は、単位であっても常に数える。`u:Sp` と書けば、その値を使える
- 値を数えない単位の要素は、値を捨てる文脈（ADR 0026）で生成する

この規則で、冒頭の例は書いたとおりに動く。

```
ExpList <- e:Exp es:(',' Sp Exp)* { e : es }   # グループの値は Exp の値
```

### 静的検査と生成

- peg-grammar の値の数え方（`hasValue` と、アクションの省略の検査）を上の規則に合わせる
- peg-codegen のアクションの省略の生成（値を一つ返す選択肢）を、数えた要素の値を返すように合わせる

## 実装しないこと

- 型の別名の解決。`type Unit = ()` のように別名で書いた型注釈は単位と判定しない。型を解釈するのは GHC であり、peg-grammar は型を文字列として扱う
- `()` 以外の情報を持たない型（`data Space = Space` など）の扱い
- 値を明示的に捨てる記法（`~Sp` のような接頭辞）。単位の値を数えない規則で、実際に困った場合はすべて解消するため

## テスト設計

- **数え方**：単位の規則を挟むグループ、単位の規則の `*` と `?`、単位の要素だけの選択肢（従来どおり単位の値を返す）、束縛した単位の要素、単位でない値が二つある選択肢（従来どおりエラー）、型の別名（単位と判定しない）について、静的検査の結果が期待どおりであること
- **生成**：上の形を含む文法を codegen の fixture に加え、生成コードがコンパイルでき、値が期待どおりであること。`%syntax` を付けた文法でも同じこと
- **既存の文法**：リポジトリのすべての文法の生成物が、生成し直しても変わらないこと。既存の文法は、単位の値を数えない規則に頼らずに書かれているため
- **書き直し**：Lua と TOML の文法から、上に挙げた補助の規則を除いてグループで書き直し、それぞれの適合性テストが通ること

## 実装の段階

ADR 0029 の後に行う。
記法の変更なので、採択するときに `docs/syntax.md` を更新する。

## トレードオフ

- 値の数え方が、規則の型注釈に依存するようになる。規則の型を `()` から別の型に変えると、その規則を挟むグループやアクションの省略の意味が変わり、静的検査のエラーになりうる
- 型の別名を使うと単位と判定されない。文法の作者に、空白の規則の型を `()` と書くことを求める
